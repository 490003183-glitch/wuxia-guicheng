# 剧本、导演、拍摄与生成的交接契约

用于小说改编、原创剧本及其导演/Seedance 交接。声音分工属于本项目实践，其他项目应明确自己的制作约束。普通问答与只读诊断无需制作全套表；单场生成只验收本场。将记录放进已有剧本审计、导演稿和制作 manifest，避免另造平行母稿。

## 本项目制作档案：禁止补配音

角色对白、通讯话语及确需保留的旁白必须在同一次视频生成中按准确文本完成。禁止独立配音、替代配音、干声采集、后期口型修复和为了取音轨另生成视频；不得把成本转移给用户。`audio_only_speakers` 仅表示同次生成内的画外角色，不是独立声音任务。已有视频原声的普通剪辑可保留，但不能以另一条录制或生成的声音替换画内表演。不得默认多拍备选；优先解决剧本表达、成品组织和提示词容量。既定来源只能靠补配音才成立时，回到剧本/导演层重做载体，不删除事实或自动增加制作工序。

## 1. 剧本先完成影视表达

小说是故事来源，剧本是拍摄所依据的故事文本。小说段落加场次、台词编号或源文旁白，不自动等于可拍剧本。关闭小说和解释材料后，演员应能从剧本本身理解场地、参与者、行动对象、发生顺序、说与不说、接收信息的途径及完成结果。

对汇报、讨论、答复、决定、回忆、心理判断等概述，先在剧本阶段选择完整的可见行动、准确对白、准确旁白或已获准的后期表达。旁白是表达选择，不是处理困难叙述的默认兜底；检验声音是否与行动共同推进、信息是否重复、画面是否只能等待解释。必要停顿要有可演内容，不能按小说段落平均分配时长。

保留原文事实、对白、信息权限、身体结果和确定性；影视转换不要求逐句把小说拍出来。授权范围内的非剧情载体修复直接完成。涉及新增对白或故事变化时，先形成具体的剧本修订提案，按既有授权处理；不得把创作留给导演编译器或视频模型。原文无逐字话语时，禁止悄悄发明台词，也不能为避免台词而删除事件。

交接分别记录：来源是否当前；源忠实审计；剧本单独冷读；语言和信息载体是否已解决。写明验收范围、证据位置及未解决项。`已确认` 是用户接受状态；`可拍性通过` 是本次制作判断，两者不能互相冒充。未解决项可随诊断或待确认剧本交付，但依赖它的导演/生成单元不得标为可执行。不要因为剧本未给可选机位、目光、站位或呼吸曲线就判不通过，这些由导演设计。

## 2. 语言内容封闭

从剧本独立提取每次话语的 occurrence ID、来源位置、说话人、接收者、准确文本及交付方式。相同文本说两次仍是两个 ID；不能从已经写出的提示词反向提取清单来证明自身正确。

- `generated_dialogue`：在拍摄单元及最终提示词里逐字列出；未列出的参与者明确无台词。
- 不设后期话语交付类型。剧本已确定的旁白如保留，也须列入同次生成的准确话语；无法同次完成时标明载体缺口并回流。
- 本条无生成话语：明确 `全程无台词`、`不生成旁白或画外人声。`。这不禁止剧本已有的喘息、痛哼等非语言声响。

禁止“自行发挥台词”“说出大意”“汇报若干情况”等开放任务。对白合并、拆分或整条视频重新生成后，逐字检查说话人、接收者、顺序、次数。没有准确对白的知识状态不是另一次通讯；已有对白后的反应与执行不能重复汇报。

## 3. 一次生成是一项独立成品任务

生成单元可以是一段连续场景、一次定向素材获取，也可以直接是一条快剪、跨时空蒙太奇、旅游 vlog 或特效剪辑成片。不要把 Seedance 仅当传统摄影机，也不要把“一次生成等于连续时间、单一地点、一次表演”写成通用限制。保留 TAKE ID 仅为旧格式追溯，它标识一次生成任务，不规定成品形态。

先确定本段需要什么成品，再判断一次生成能否完成；模型内部快剪、转场和特效属于该次成品生成，外部把多条生成结果拼起来才是后期装配。普通连续场景用 AUTO_EVENT；直接生成完整剪辑段用 AUTO_EDITED；某个不可替代视图才用 DIRECTED_CAPTURE。三者都须保留准确台词、源事件、人物身份、信息权限和动作结果。自动剪辑不等于自动编造剧情；特效是表现手段，不自动增加角色能力或世界事实。

连续场景：兼容的对白、反应和执行优先合并，不因 SH、短反应或一句话而拆条。快剪/蒙太奇：明确完整成品目标、覆盖的地点和时间片段、允许省略的连接过程、节奏及视觉效果方向，让 Seedance 组织内部剪辑；跨时空本身不是拆开生成的理由。原本能一条完成的剪辑成品，不先拆成许多视频让用户手动重组。

每条记录生成形态、整体内容计划、覆盖的源事件和 SH/ED、准确话语、预计生成时长及容量依据。连续模式检查连续状态；剪辑成品模式逐片段检查时间、地点、身份和结果，不能要求空间不变或把合法时间省略判成状态跳变。不要为了复用连续场景 schema 填造一个统一地点或连续时间组。每次额外生成仍需具体原因；条件备选不默认执行。

## AI 导演与成本交接

导演负责适合 AI 生成流程的整集成品方案。先选择成品形态和可复用资产，再细化真正必要的镜头；传统拍摄知识只服务观看效果，不默认导出逐镜付费、多角度覆盖或保险条。P0/P1 保护结果，不要求一项一条。优化调用数、生成时长、新增资产、失败返工风险及用户手工工作量，不能以丢剧情或不稳定硬塞来减少表面次数。

导演稿在现有生成表旁汇总主方案调用数/生成秒数，必要独立插入计入主方案，条件备选另列触发条件及替代对象、首轮不执行。资产 skill 不提前制作仅供未触发备选的图片；编译 skill 不把 SH/ED、优先级或保底项自动扩成额外付费调用。确需改变主方案时回流版本化导演安排并更新汇总，不能只在下游偷偷加条。

## 声音职责

音效制作由用户负责。导演/编译 skill 只保留准确对白和改变剧情理解的必要声音事实，例如人物听到警报才作出反应；不默认安排音效表、混音、声音桥、音轨提前、额外声音素材或音效生成任务。

《雾峡轨城》禁用 J-cut，包含改名为“下一场声音先入”“音轨提前”等同一做法。其他项目不自动禁用，但 J-cut 不是默认转场，也不因模板存在就规划。此规则不禁止准确画外台词、剧情必要声音或用户自行制作音效。独立/替代配音的禁令继续有效。

## 4. 连接与变更回流

- 剧本缺行动、准确话语或信息载体：回到对应剧本 skill 修复；导演承担可选表演调度和声画设计，不索要剧本预写机位。
- 导演缺 TAKE、时长依据、拆分理由：在授权的导演工作版本内补全；编译器不按 SH 自行重新分组。已确认母稿先保留，必要修订作为新版本或明确的待确认补充，不默改后继续使用旧 hash。
- 资产跟随当前导演 TAKE 的真实空间和状态；同剧本换导演也要重核交接。不能为了复用资产改变剧本或恢复导演已取消的门区调度。
- 用户禁用字幕、旁白、界面或某个表现手段：该载体原先承载的事实仍保留，回到负责层完成等价替代；无法替代时列明具体缺口，不用“继续办理”等抽象动作填洞。
- 已获准的后期文字、静态结果进入 post_units 与剪辑引用，不伪装成 Seedance 提示词，也不能在导出时丢掉。剧情必要的非语言声音保留在源事实和同次视频内容中；不新增 post_units 声音任务，音效制作由用户负责。
- 新版本按路径、版本、状态、hash、取代对象及接收方行动交接。只更新 hash 不能修复内容过期。

## 5. 制作包的可验证记录

导演格式见 [director-draft-format.md](../../direct-edit-canon-episode/references/director-draft-format.md)。本公开包不附带平台编译器或自动执行 schema。基本交接在现有剧本与导演稿记录来源状态、准确话语清单、每次生成的内容与时长、编辑单元对应关系即可；平台生成另按使用者实际工具处理。

另接平台验证器时，它只检查契约、绑定、引用、逐字话语、次数和拆分理由等可计算条件；它不证明剧本艺术质量、台词清单完整性、导演调度合理性或某个载体的源依据。来源对照与独立冷读必须实际进行，不得用填入 passed 代替。
