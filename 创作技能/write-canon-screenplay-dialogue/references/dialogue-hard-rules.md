# 台词硬规则

本文件存放台词写作、改写和审稿时不得违反的阻断规则。命中任意硬规则即视为审稿失败，必须修改后才能交付；只有用户在当前任务中明确要求保留原句时才可例外，并需说明例外。

## H001 禁止“不是 A，而是 B”式台词

- 状态：硬性阻断
- 范围：角色对白、画外音、旁白及其他会被演员说出的文字
- 目的：避免解释腔、总结腔、对称说理腔和明显的模型化表达

### 禁止形式

- `不是 A，而是 B`
- `不是 A，是 B`
- `A 不是 B，而是 C`
- 把前后半句拆成相邻两句，实际仍构成同一组纠正式对偶
- 用停顿、括号动作或标点变化掩盖上述结构

### 不属于本规则的情况

- 单纯否定事实且没有接续纠正式结论，例如：`这里不是出口。`
- 动作描述、审稿说明和制作备注中的必要分析文字；这些内容不属于角色台词

### 改写顺序

1. 直接说角色真正要表达的结论，删除前置否定。
2. 改成可执行的命令、观察、后果或即时反应。
3. 用人物动作承担对比，不让角色把两个概念完整讲成对偶句。
4. 保留角色口气、身份和关系压力，避免改成另一种书面解释腔。

### 示例

禁止：

```text
“这不是蛮力，而是失控。”
“别抓住。不是抓，是贴着继续进。”
```

可用：

```text
“你的力已经散了。”
“手别抓死。贴住了，继续往里进。”
```

## 审稿执行

- 写作前读取本文件。
- 完稿后只扫描实际说出的文字，不要拿动作描述代替台词检查。
- 可用正则初筛：`不是[^。！？\n]{0,40}[，,；;]?\s*(?:而)?是`
- 正则只负责发现疑似命中；最终按句意判断是否构成纠正式对偶。
- 命中后必须重写并重新检查，不得以“角色正在讲理论”为理由放行。
