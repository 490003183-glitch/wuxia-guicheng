# 原创剧本与可演对白

没有小说母稿时，直接从用户简述、正式资料和明确标识的创作推断构建剧本。用户指定小说为叙事来源时转同级 [小说改编技能](../adapt-canon-novel-to-screenplay/SKILL.md)。

## 范围与依据

- `CANON_ROOT` 是使用者指定的正式来源，`OUTPUT_ROOT` 放草稿。查项目、当前状态与本场相关角色/地点，不盲读全库。
- 选择原创模式、剧本母稿修订模式或只读审阅。原创不假造小说来源；已有母稿按 [事件保留](../write-canon-novel-prose/references/canon-event-preservation.md) 保护确认事件。
- 资料分为正式事实、原始参考、待确认推断。完成草稿不自动成为正式设定；只读审阅不自动授权改写。
- 角色语言/表演档案如果存在，按实际发言人物读取。没有档案则用已确认对白与客观行为作有限校准，不虚构演员指纹，也不要求另装技能才能开始。

## 本场故事发动机

写作前私下确定：本场属于推进、人物转折、间章还是兑现；中心人物当下想要什么；不想让谁看见什么压力；实际什么成功、失败或被拒绝；结束后什么不可逆地改变；信息、关系和物理状态怎样交给下一场。

程序、技术展示和世界说明不能代替人物欲望。因果成立后，关闭清单写连续可演场景，不把每条事实分配给不同人物讲解。

## 对白与表演

1. 判断谁有理由开口、谁有权提问或不回答。关系、身份、恐惧、面子、想被相信和自我调节都可以产生语言；每个出场人物不必有台词。
2. 区分语义意图、表面说法、稳定人物表现和本场可见反应。资料只约束表达，不授予新知识、新关系或新能力。
3. 让说话人对具体的人做事：争取、拒绝、掩饰、试探、打断、求助。不要替作者总结规则、宣布心理结论或排队讲设定。
4. 保留合理的重复、碎句、拖音与不完美口语。自然短句不强加“解释第二拍”；关系戏也不把所有人压缩成相同短答。
5. 读 [对白硬规则](references/dialogue-hard-rules.md)。原作冻结台词与风格规则冲突时报告，不悄悄改字。
6. 行动、接触、伤势、物件状态与结果写清完成程度。故事已命中不能改成挥向或差点命中。

剧本负责故事事实和必要可演载体；导演负责可选站位、目光、距离、景别、呼吸调度、镜头和剪辑。删掉会改变事实或确定性的动作留在剧本；只是表达既定事实的可选方法留给导演。

## 格式与验收

正文至少包含场次的时间、地点、出场人物、可见可听的顺序行动、清楚的说话人和完整台词。准确说话内容与沉默在本层解决，不能把“收到答复”“汇报情况”留给生成工具猜。

正文外简短列出正式依据、推断、本场语言约束与必要演员执行提示；不逐句解释所有潜台词。具体制作交接遵循 [交接契约](references/production-handoff.md)。

完稿先核对因果、信息权限、源事件、接触与结果，然后关闭说明材料独立冷读。区分剧本载体问题、故事问题和导演问题，只在已有授权内修复。冷读检查人物吸引力、字面可懂、空间、节奏、兑现及结尾，不用 hash 或规则通过代替。

交付标明 `剧本原创／待确认` 或当前来源状态，准确报告已改与未改。只有明确保存或定稿授权才写入指定目标。保留可恢复历史，更新实际受影响的版本链接；不自动生成小说、提示词、图片、音频或发布内容。
