# 静态资产图提示词

使用用户指定的正式来源、资产清单和输出位置，不要求特定知识库或资产管理程序。本公开版不附带私人风格参考图；风格参考由使用者提供且确认可用于当前任务。参考只按指定用途锁身份、结构或风格，不能将图中人物、文字、装备和布局一并当成设定。

## 规划与参考

已有 derive-director-asset-plan 计划时处理未解决 CREATE。没有计划时可直接按剧本规划，不强制先写导演稿。基于真实清单核对精确 ID、状态和文件，不凭名字与视觉相似声称可用。

按依赖排序：独立细节装备 → 场景母版 → 必要视角或状态派生。只在依赖结构尚未确认时等待该项确认，已授权已确认部分继续。每项说明目标、来源、依赖及验收标准。

- 细节、装备、道具宜用中性背景表达结构，小物可做资产卡。
- 场景母版展示连续真实空间，默认 21:9，用户指定比例优先；比例同时写入提示词和验收标准。
- 拍摄参考默认右上角资产 ID 和名称；无字原图和成片画面按用户要求。
- 3D 截图可直接作空间参考，保留出口、通道、遮挡、路线；辅助线和文字不是场景实体，未知尺寸不猜成精确值。
- 持续灯光、损坏和开闭派生仅改已授权状态，沿用母版几何和实体编号。
- 复杂大空间的自然设施编号在同一提示词描述；沿用已有编号，不强求连续，不要求使用者手工登记每个号码。
- 站位能用短文字说清时不再造图。必须看多人静态关系时使用母版上的简化体块，不重设环境。

## 门区与跨越

仅当导演选择实际展示跨越时，证明同一开口两侧和贯通关系。可以规划 9:16 总图，上中下为出发侧、贯通状态和到达侧横幅子图，保持门框、开向、地坪、光源与固定锚点一致。单场景视频使用独立子图，避免直接上传三联图造成分屏。

背景门无需三图；只开关不跨越可用同侧状态图；导演已采用离场与结果衔接时不重新加回穿门。具体组合取决于事实，不按所有门机械套用。

## 交付

一资产一区块：ID 名称、来源依赖、验收标准、按上传次序的参考图与继承边界、生成设置、完整提示词。不要把参考图集中到前面让用户反复查表，复用参考也随条目展示。

提示词描述用途、主体、空间、构图比例、结构材料、光色、标识和必须出现的事实。参考路径与工作元数据放正文外。不补出正式来源没有的功能。

两项以上可用附带网页渲染器；用户要求纯文字则直接交付。读 [清单契约](references/delivery-schema.md) 后，在本技能目录运行：

```bash
node scripts/render_asset_prompt_delivery_html.mjs ./delivery.json --output ./delivery.html
```

Node.js 18 或更新版本，仅标准库。网页展示图片、逐条复制路径与提示词。待生成依赖只显示说明，不冒充现有文件。它不会调用生成或上传服务。网页通过本机 file URL 引图，适合本机打开；分享网页需处理图片可访问性和本地路径隐私。

交付前核对区块顺序、真实图片、依赖占位、复制内容和窄屏阅读。渲染通过只证明必填字段与文件路径通过检查，不证明画面符合设定。生成、移动和主库写入遵循明确授权。
