# 可见身份与体量

当本块出现非普通人类、异兽、机械体，或已有体型／形态误生成反馈时，优先复用已确认的身份事实；必要事实缺失时定向读取正式角色／型号页和资产卡。参考图继承范围由用户告知，不默认逐图分析哪些部分应该继承；用户要求查图或出现具体外观冲突时才核对相关图片。将已确认的最短完整身份锚点保留在本块 `special_rules`：是什么、会影响动作的体量或比例、辨认该个体的必要材质与结构。每个独立生成块单独保留，不能让上一条、上传文件名或网页图片说明代替可复制提示词。普通人物已有完整人物卡时不逐项抄写外貌百科。

这些是静态外观约束，不是新动作、机位、能力或展示要求。只写本块确实需要的部分；只提到名字、仅画外声音或用于与另一个体区分，不等于本体出镜。当前形态与参考图不一致时回查来源，不凭图猜米数、体重、年龄或变体，不增加补图及生成次数。

## 圈圈：已发现并需要拦截的回归

正式依据：

- 母版 `WXGC-CHR-24700930-EP28-001` 及同名资产卡。

当前来源支持：大型灰蓝猫科阿尔法异兽、宽厚肩背与结实躯干、灰蓝斑驳短毛、无颈环、长尾与蓬松尾端连接处的浅色小环。小说中肩背几乎碰到通道两侧、亲近时把蹲着的乔昔撞坐在地上，支持明显大于家猫的体量；没有精确肩高、体长、体重或年龄。伏低和钻行不得变成缩小身体。硬质皮层已废弃；尾环的存在不触发毒针能力描述。

圈圈出镜的每块应在局部规则中明确以上基本身份。措辞可变；`圈圈无颈环`、`按人物卡`和`不要生成小猫`均不能单独满足正面物种与体量描述。不可把圈圈的个体特征移给敌方阿尔法，或把敌方颈环移给圈圈。

`scripts/visual_identity.mjs` 是这次已知回归的最低检查：按可见状态、可见动作或本块母版上传触发，编译阶段与最终提示词阶段共用；旧版只写无颈环应失败。仅对白提名、未出镜及其他阿尔法不触发。这个检查不证明全部外观或三维比例正确，也不自动替其他角色生成设定；后续新例仍按正式资料作语义核对。

## 字数不足时

当前本地连续提示词校验器采用每条 **2400 个 Unicode 字符**的预算（含空白和标点），这是本地检查阈值，不当作已经验证的官方平台上限。校验器只报超长，不截断、不删写提示词。

准确话语、关键动作因果、跨条状态与必要身份／体量都是受保护内容。先缩短重复修饰、重复解释及与本块无关的能力说明；冻结 global 按现行契约保留。不得为过校验删除基本外观、缩短准确对白、抹掉移动距离或把巨兽缩为小动物。仍超长时报告实际字符数与缺口，在已有授权范围内调整组织；不能静默拆成更多收费生成任务，也不能把缺失事实藏到网页说明。长度合格从来不代表信息完整。
