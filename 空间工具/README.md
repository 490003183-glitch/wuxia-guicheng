# 空间工具

《雾峡轨城》用于辅助小说、剧本和导演稿的交互空间浏览器公开版。保留全城立体基准、逐章地点路线、EP31局部空间、行动时间线和审阅反馈。

## 打开与使用

下载仓库后，用现代浏览器打开本目录的 [index.html](index.html) 查看全城，或打开 [ep31.html](ep31.html) 查看第三十一章。两页均可离线运行，不需要账号、联网服务或安装 JavaScript 依赖。GitHub 文件页面展示源码，下载后打开才能操作。

- 全城：58 个地点、EP01—EP31 路线，支持剖开外壳、旋转、缩放、按地点定位。
- EP31：局部空间、7 段路线、4 条并行时间线；可按事件时间查看位置与通行条件。
- 空间意见只保存在当前浏览器，可生成、复制或下载反馈；不会修改小说、设定或向服务器提交。
- “一键截图本集全部空间”导出 18 张 JPG 和清单 ZIP。导出图是工作空间参考，不自动成为正式美术资产。

## 源码与修改

需要重建网页时，使用 Python 3.9 或更新版本运行：

```bash
python3 build.py
```

脚本只读取本目录的 `src/` 与 `data/`，重新生成 `index.html` 和 `ep31.html`，不访问任何私人知识库。

- [data/global.json](data/global.json)：全城几何、地点与章节路线。
- [data/ep31.json](data/ep31.json)：EP31地点、路线、事件与时间线。
- `src/`：页面模板、样式、SVG投影、时间联动、反馈和截图程序。
- `build.py`：仅使用 Python 标准库的构建脚本。

这仍是围绕《雾峡轨城》与 EP31 制作的工具。全城数据可以替换；EP31的模型、事件范围和部分交互映射也写在 `src/model.js`、`src/view.js`、`src/logic.js` 中，迁移到其他章节需要同时修改，不能只换文件名。

## 数据边界

本版数据来自项目的工作空间规划，已经按公开版小说调整。坐标、尺寸、耗时及历史地点序列是创作辅助信息，不等于已确认的正式设定或完整交通网络。涉及剧情时以[公开版小说](../小说/README.md)和[世界观](../世界观/README.md)为准。原始私有来源映射、图片绑定和内嵌参考图未纳入。

数据修改后应重建两页，核对连通关系、路长、高差、通行方式和多人事件时间。反馈与截图包含公开空间版本号及数据哈希，可用于追溯讨论依据。
