# 对白常见失败与改写

> 作者：mtgh · 公开版制作资料

## H001 禁止纠正式“不是 A，而是 B”句式

### 禁止

- `不是 A，而是 B`
- `不是 A，是 B`
- `A 不是 B，而是 C`
- 拆成相邻两句、用停顿或括号动作遮掩，但语义仍然是同一组纠正式对偶

### 允许

- 单纯否定事实且后面没有纠正式结论，例如：“这里不是出口。”
- 动作描述、审稿说明、制作备注中的必要分析文字；本规则只阻断会被说出的文字。

### 改写顺序

1. 直接说结论。
2. 改成可执行命令、观察、后果或即时反应。
3. 让动作承担对比，不让人物完整说出 A / B 对偶。
4. 保留角色口气和关系压力，避免改成另一种解释腔。

### 示例

```text
禁用：“六大开里的‘缠’。不是抓住，是黏住以后继续进。”
可用：“六大开里的‘缠’。手别抓死。贴住了，继续往里进。”

禁用：“八极的刚，不是全身僵住。”
可用：“八极的刚，靠松紧变化。”
```

## H002 禁止镜像否认对拍

### 禁止

```text
A：你 X 了。
B：我没有／我没／哪有。
```

- “你明明……” / “我哪有……”等近义替换仍属同一结构。
- 指控后立即给出句法镜像的否认，即使中间插入一个动作也不能通过。

用户否定样本：

```text
“你动了。”
“我没有。”
```

### 改写顺序

1. 删除整组对拍。
2. 让动作、读数或后果证明发生了什么。
3. 让第二个人物回应现实风险、体面或其他实际注意点。
4. 确有必要时延迟回答，不把否认写成第一反应。

## H003 禁止拟人化教练金句

### 禁止

- `别跟 X 抢／较劲／对着干。`
- `让 X 跟上你。`
- `看 X 能不能跟上你。`
- 用机器、力量、城市或身体的拟人比喻替代具体技术观察。

用户否定样本：

```text
“别跟它抢。今天看它能不能跟上你。”
```

### 改写顺序

1. 删除，不寻找更新鲜的比喻。
2. 用读数、身体结果、系统反馈或动作承担信息。
3. 确有口头指令需要时，只说可执行动作或可观察后果。
