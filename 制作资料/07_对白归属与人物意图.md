# 对白归属与人物意图

> 作者：mtgh · 公开版制作资料
> 已整理的项目实践，供创作参考；具体场景以公开版小说、剧本和设定为准。

## 用户确认的四类硬失败

### 1. 镜像否认对拍

禁止结构：

```text
A：你 X 了。
B：我没有／我没／哪有。
```

以下换词仍视为同类：

- “你明明……” / “我哪有……”
- “你又……” / “我只是……”
- 指控后立即出现句法镜像的否认。

失败原因：第二个人物只是在替第一句完成节奏，两个人像同一个作者的上下句。

### 2. 拟人化教练金句

禁止结构：

```text
别跟 X 抢／较劲／对着干。
让 X 跟上你／看 X 能不能跟上你。
```

失败原因：把具体物理或技术问题包装成可摘抄的导师句，人物、设备和危险都退成了金句道具。

禁止用另一个比喻修理。处理顺序是：删除；让动作或读数承担；给具体后果；最后才考虑必要的短指令。

### 3. 人物没有信息缺口的作者搭台问句

用户否定实例：

```text
终端已经提示：室外低速行走。

步小蛮：“今天放哪些？”
林逸：“腿。”
```

失败原因：步小蛮已经知道本次训练内容，问句没有人物层面的未知；“放哪些”也没有此前建立的共同术语。整组对白只用于让林逸接一句“腿”，方便作者继续说明训练权限。删除两句后，人物行动、训练步骤和关系均不改变。

此类问题不能改成“开什么”“解锁什么”或“今天练什么”继续保留。若人物没有真实信息缺口，应直接删除问答，让终端状态、人物动作或训练后果承担信息。

### 4. 说话人归属不明

用户指出清单第 25—29 项小说原文中的引号段落难以判断是谁在说话。此类问题不属于读者理解能力不足，而是正文没有提供足够稳定的说话人标记。

以下情形按硬失败处理：

- 三名及以上可能说话的人在场，换人后只写裸对白或`她说／他问／对方回答`；
- 人物动作、系统信息、场景说明或较长叙述插入后，下一句对白仍要求读者沿用插入前的轮次；
- 先写甲的动作或视线，下一行直接出现乙的台词，却没有写明乙先开口；
- 同一名未命名角色在`工作人员／白塔的人／技术人员／处置员`等近义称谓间切换，使读者误以为换了人；
- 连续裸对白依赖一问一答的交替顺序才能判断说话人。

修复要求：

1. 三人以上场景中，每次换人开口都在同一段使用姓名、固定身份或唯一人物动作重新锚定。
2. 两人场景在开场、插入动作或系统信息、注意力转移、场景切换和连续两轮裸对白后重新锚定。
3. 一个对白段落只属于一名说话者；动作与台词必须归于同一人。若甲正在动作而乙抢先说话，正文必须明确写出乙的姓名或身份。
4. 清晰不等于逐句机械添加`某某说`。可以使用`罗小雨关掉页面`、`乔昔指着清单`等人物动作，但动作必须足以唯一确定说话人。
5. 冷读时逐句遮住前后对白，只保留当前段落；若仍不能立即指出说话人，该段不得保存。

## 语义级阻断

以下结构即使没有命中固定词，也必须人工拦截：

- 提问—否认—纠正—解释—聪明收尾的教程楼梯。
- 两个人轮流说长度相近、结构相反的句子。
- 一个人搭台，另一个人反转，前者再补一句封口。
- 导师或强者用拟人比喻替代可执行信息。
- 最后一句总结本场主题、关系或人生道理。
- 删除人物名后，整段可以无损移植给任何两个人。
- 人物已经知道答案，却仍提问以便另一人解释设定、宣布步骤或引出术语。
- 问句使用了此前未建立的行业黑话、设备简称或共同说法，只为了显得简洁专业。

## 阅读检查

逐场检查人物知道什么、想做什么、在对谁说话。三个以上角色在场时，换人开口要重新锚定说话者。删除不承担人物意图的问答和总结句；保留有生活、关系和情绪意义的闲话。扫描只能发现已知句式，不能证明对白自然。
