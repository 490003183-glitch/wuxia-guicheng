# 雾峡轨城 9月22日 C场：巡逻事件复盘与权限阻隔公开版剧本

> 作者：mtgh · 公开版


### 一、任务复盘室

白塔任务复盘室。

冷白灯光。墙面浮着一组巡逻记录：

```text
9月21日｜商业区巡逻
异兽颈环：已销毁
隐藏炸弹：已解除
任务状态：完成
```

罗小雨站在记录屏前，没有坐。

沈砺坐在桌边，手指划过最后一条记录。

沈砺：
巡逻部分已经对完了。颈环销毁，炸弹解除，现场没有二次伤亡。

罗小雨：
我想问步小蛮。

沈砺停了一下。

沈砺：
她上午做了身体检查。

罗小雨：
她受伤了？

沈砺：
目前没有需要处理的伤。

罗小雨看着他。

罗小雨：
那她为什么还要进检查室？

沈砺没有马上回答，调出另一层记录。

屏幕上只出现一行：

```text
身体检查记录：特殊安全等级
访问受限
```

罗小雨往前一步。

罗小雨：
我能看哪一部分？

沈砺：
巡逻记录。

罗小雨：
身体检查呢？

沈砺：
不在你的权限里。

罗小雨：
我申请查看。

沈砺把申请界面转向她。

申请按钮是灰的。

沈砺：
入口没开。

罗小雨盯着那行字，手指悬在屏幕上方。

罗小雨：
谁关的？

沈砺：
授权链只显示等级。

罗小雨：
你也看不到？

沈砺：
我能看到的，就到这里。

罗小雨压住呼吸，收回手。

罗小雨：
我陪她长大。她不舒服的时候，嘴上也会说没事。

沈砺看着她，没有接这句话。

罗小雨：
她今天有没有风险？

沈砺：
当前没有需要紧急处置的风险。

罗小雨：
“当前”是多久？

沈砺：
这份复核只覆盖今天。

罗小雨转头看向屏幕。

另一条安排记录一闪而过：

```text
下午训练：已转入新授权安排
```

罗小雨捕捉到了那一行。

罗小雨：
谁接手她的训练？

沈砺：
这条权限我不能在这里打开。

罗小雨沉默。

她重新看了一眼“特殊安全等级”，拿起自己的终端。

罗小雨：
好。

她转身离开。

门在她身后合上。

屏幕上的访问限制仍然亮着。
