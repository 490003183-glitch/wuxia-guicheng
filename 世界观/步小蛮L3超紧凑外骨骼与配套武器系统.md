# 步小蛮L3超紧凑外骨骼与配套武器系统

> 公开版｜来源状态：已整理。包含剧情剧透；文内未来节点及待确认项不代表已经发生。

## 定位与来源等级

本页供后续小说、剧本、导演和资产规划调用。系统定位为超紧凑型贴体外骨骼战术机甲：精密设备、人体工学、轻量化承力骨架和半透明材料结合，保持穿戴者原本比例。它是L3穿戴系统，不是L2旧巡检甲的别称，也不是有驾驶舱的大型机甲。

- **既有正式设定**：L3增强力量、速度、跳跃、反应与耐力；正常不可见的防御能量场覆盖穿戴者及外骨骼整体，防护强于L2，但遵循动量守恒，不保证机体不受损。
- **仅图示资料**：比例栏中的步枪约85厘米、浮游模块单体约20厘米、储能单元约15厘米，作为图示工作尺度；不据此推出射程、续航、威力或全装备的工程参数。

## 一、系统组成：不要把不同部件混在一起

| 系统 | 结构与资料明确的能力 | 主要用途 |
|---|---|---|
| 外骨骼本体 | 窄型承载脊、肩胛驱动单元、腰髋连接和沿四肢关节布置的助力链；力量、速度、跳跃、反应与耐力增强 | 穿戴者自主行动，机械结构提供助力与支撑 |
| 背部推进器 | 左右各两个，共四个短小紧凑矢量喷口，贴近肩胛和承载脊；短时推进与空中姿态调整 | 爆发位移、跳跃修正、改变短时运动状态 |
| 模块化高能线性步枪 | 图卡称模块化能量步枪；约85厘米工作尺度，可拆分收纳及挂载 | 中远距离精确打击，作为独立手持主武器 |
| 四枚浮游攻击模块 | 与步枪、固定喷口相互独立；自动追踪、辅助锁定、协同打击；有收纳、飞行、攻击形态 | 辅助攻击、侧向作用、独立部署与短时环绕防御 |
| 机械高跟足 | 窄前足机械鞋壳、独立细长后跟支柱、踝部转轴及减震执行器；可随站立、冲刺和跳跃调节角度 | 足部支撑、姿态适配、着地缓冲，与腿部动力链连接 |
| 防御能量场 | 正常完全不可见，覆盖人体和机体，防护强于L2 | 抵挡伤害，不能取消命中冲量和失衡风险 |
| 图示储能单元 | 图卡比例栏展示独立块状单元 | 能源组件的外观资料；具体安装、分配和更换方式未明确 |

**关键区分**：固定的四个喷口不是四枚浮游炮；步枪拆出的零件也不是自动获得独立作战能力的小枪。浮游模块飞行／攻击展开不等于整套外骨骼变形。紫色喷口内环是设备局部视觉，不能把它扩成可见防御罩。

## 二、外观与穿戴结构

- 冷白为主要外壳，浅薰衣草紫为识别面、边缘件、关节护盖和低亮状态灯，深石墨灰为承力骨架、连杆、转轴、驱动与内层固定件。保持克制，不能把低亮识别色扩成全身霓虹。
- 肩、胸、髋、腿部是细长圆角分片甲；缝隙窄而清晰，连接件精密小型。不要粗大液压杆、粗壮工业机械臂或全覆盖动力甲。
- 胸部左右分区随身体曲面；腹部主要为透明或淡烟紫半透明结构层，中轴和腰侧有细型承力连接。透明是材料属性，不等于隐身、投影或防御场可见化。
- 腰线收束，髋部小浮动甲片不组成厚裙甲；大腿主要沿外侧及局部前侧布甲，不画整圈厚腿甲。机械手套覆盖手背与部分手指关节，仍然纤细。
- 机械高跟足不是普通高跟鞋外套装甲，也不是原L2行动鞋。穿戴者原有身体比例、面部和发型不被机甲重塑。
- 本体有实际固定扣、关节与可拆卸结构，可以由他人辅助扣合。半透明外观不能推出脱甲后的内衣颜色、裁片或内衣取消；脱甲状态依对应场景来源另行确定。

## 三、能力、用途与用法分析

以下每节先列资料依据，再列可供后续创作选择的用法。动作方案尚未发生时，不写入章节履历。

### 1. 外骨骼助力：让人更容易完成动作

**依据**：正式L3分级确认五项增强；设计资料将肩—上臂—肘—前臂与髋—大腿—膝—小腿—足部连接为贴体动力链。

**用途分析**：适合需要步行、攀行、短程奔跑、转向、搬动和控制身体重心的城市行动；保留人体能通过的通道尺度。它能减少动作的体力门槛，但使用者仍要判断路线、控制姿势和选择时机。

**用法建议**：穿戴并检查固定后先做抬脚、迈步、转身与扶物试力，再进入复杂行动；描写关节发力与身体结果，而不是让装甲自己拖着人走。需要推、撑、撞或落地时，让受力通过人体与外骨骼支撑关系成立。

**边界**：反应增强不等于读心或预知攻击；助力不自动赋予格斗经验。已有疲劳、掌心发麻、疼痛与惊慌不会因换甲瞬间消失。不能把L3写成跨越L4、L5等级的必胜装备。

### 2. 固定四喷口：短时机动与姿态修正

**依据**：上背左右各两个紧凑喷口，图示矢量结构；设定明确短距离爆发推进、快速位移、跳跃修正和空中姿态调整。

**用途分析**：可补充腿部助力，处理起跳后落点修正、短暂改变运动方向或脱离原有攻击线；特别适合立体城市中的局部高差与通行窗口。

**用法建议**：先有可行路线或落点，再安排短时推进和身体姿态变化；支撑面、起跳、短推、修正、落地各有结果。四喷口可用于表现分侧调整，但具体喷口偏转幅度与推力分配未定，不写成任意方向瞬间平移。

**边界**：没有确认持续飞行、无限悬停、跨城区飞行、瞬移或无惯性急停。狭窄场地应先看净空和落点，不能穿墙或越过被封死的结构；具体尾流温度、喷焰长度与燃料机制未知。图上长发靠近背部设备，资料未说明进排流与头发保护结构，后续局部特写若涉及该处需设计清楚，不能凭空宣布喷口灼伤或卷发。

### 3. 模块化能量步枪：集中、可携行的主火力

**依据**：中远距离精确打击、轻量化高输出、模块化拆分；设计说明可挂载于腰侧、背部或大腿外侧。

**用途分析**：承担需要主动瞄准和较集中输出的正面攻击；与穿戴者的稳定支撑配合，比仅凭外骨骼近身接触更适合距离较远的目标。

**用法建议**：在叙事中区分收纳、取出／组装、持用和再次收回四种状态。需要用枪时先让武器到手并形成完整可用形态；空间狭窄时应考虑长枪与转身的关系，不能在上一段空手、下一段凭空出现整枪。各模块的接口外观按图卡，不逐帧要求复杂拆装。

**边界**：具体射程、射速、充能时长、发射模式、弹药或能量消耗、穿透能力未定；“能量步枪”不自动等于贯穿建筑的激光束。没有确认拆下的每个小模块都能单独射击，也没有确认无声、自动命中、穿墙锁定或与步小蛮的暗域能量相连。

### 4. 四枚浮游模块：分散作用与协同

**依据**：四枚独立微型攻击模块，辅助锁定、自动追踪、侧向攻击、协同打击、独立部署与短时环绕防御；收纳、飞行、攻击三态在图卡中分开展示。

**用途分析**：它们可以在穿戴者持枪或移动时承担另一方向的辅助作用；浮游部署使作用方向不必完全受手臂朝向限制。对故事的价值是增加可选作用位置，而非自动消除所有死角。

**用法建议**：使用前交代本次实际携带数量，从收纳位置释放，经真实可飞行通道到达工作位置；再根据当前目标完成辅助锁定或攻击，最后回收或留下明确去向。可选用法包括主枪牵制时一枚侧移辅助、几枚分侧形成交叉关注、撤离时部分模块留后短时掩护。并非每次都要四枚齐出；是否能分别分配目标、控制方式与自动化程度仍需剧情定义。

**边界**：“环绕防御”已作为用途提出，但实现方式未定。本页不将其落实为球形护罩、全向拦截或替人承伤；模块如何识别威胁、通信距离、抗遮挡／干扰能力、能否在失联后作战均未知。不能让它们从密闭箱或墙后直接出现在目标旁，也不能无交代从四枚增殖为一群。

### 5. 机械高跟足：支撑与缓冲也是动作条件

**依据**：细长后跟支柱通过小转轴和减震执行器接踝部；设定明确可在站立、冲刺、跳跃中调节角度。

**用途分析**：前足、踝部和后跟共同完成穿戴姿态适配，腿部助力可以延伸到足端。高跟造型是这一套设备的视觉身份，并不意味着普通高跟鞋具有同等功能。

**用法建议**：站立时有明确支撑；起步、加速和落地时表现踝部／后跟角度调整、足端接触与身体平衡。越过窄缝、碎屑地面和池沿时仍遵守实际接触关系，动作不能只靠“高科技”略去。

**边界**：没有确认吸附墙面、磁力锁脚、折叠成平底鞋、滑轮、足底喷射或把细跟当成穿甲武器。防滑与缓冲不是任何表面绝不失足，也不保证任意高度落地无伤。

### 6. 防护与能源：保护不等于取消代价

**依据**：防御场覆盖人体与机体，正常不可见，强于L2，仍遵循动量守恒；图卡另有储能单元外观。

**用途分析**：防御、助力、推进和武器共同构成整套装备的使用能力；是否共用供能尚未明确。能量管理可作为后续设计方向，但不能提前指定耗尽顺序或数字预算。

**用法建议**：受到攻击时可表现装备和身体被推动、失衡、接触面承压及恢复姿势；正常状态不增加光罩、波纹或发光外壳。后续若要使用耗能选择推动剧情，先在该章规划中补足明确的可用状态和变化依据。

**边界**：储能化学／物理原理、供能总量、充电补给、各部件是否独立供能或热插拔、热管理、故障模式均未定。不能因为图上有储能块就推定成无限能源，也不接入尚未确认的暗域供能或身体消耗机制。

## 四、组合调用：可选战术，不是新增章节事实

| 使用配置 | 适合的创作用途 | 需要交代的条件 |
|---|---|---|
| 本体穿戴、无武器 | 紧急撤离、穿越通道、躲避与短距离接触 | 人仍要控制助力；固定喷口虽存在，不代表本次已启动 |
| 本体＋步枪 | 有瞄准条件的中远距离应对 | 武器确实携带、取用完成，支撑与视线成立 |
| 本体＋少量浮游模块 | 移动中兼顾另一方向、局部掩护 | 释放位置、通行路线、目标信息和回收去向 |
| 步枪＋浮游模块 | 主方向与侧向协同，分担注意目标 | 先确认该次任务配发，两种武器各自作用清楚 |
| 推进＋腿足助力 | 短时跨越或位置修正 | 净空、方向、落点及随后支撑，不把它写成长途飞行 |

主武器、浮游模块与本体可以在设定层描述为配套系统；每次出场仍按剧情实际携带与启动状态决定。后续让某种能力首次进入行动时，应给一个具体、可见的用途和结果，不能因为资产图画了就倒写前一章已经用过。
