# 2470护甲与机体等级体系

> 公开版｜来源状态：已确认。包含剧情剧透；文内未来节点及待确认项不代表已经发生。

## 总则

- 护甲、外骨骼、机甲和生物机甲统一使用`L1、L2、L3……`描述技术／战斗等级。
- 等级理论上没有上限；当前正式定义只到L6，暂时没有L7。
- 等级越高，制造、维护与使用成本越高。
- 等级只表示综合技术与战斗层级，不表示尺寸；L5在2470年仍归为紧凑型机甲。

## 当前分级

| 等级 | 当前正式定义 | 防护与增强 |
|---|---|---|
| L1 | 白塔工作人员基础护甲 | 无能量场；提供基础防弹。 |
| L2 | 罗小雨送给步小蛮的旧白紫色巡检护甲 | 价格昂贵；以贴身人员基础能量场保护身体，不保护外部机甲；不增强力量、速度、跳跃、反应或耐力。 |
| L3 | 超紧凑型外骨骼系统 | 同时增强力量、速度、跳跃、反应与耐力；自带覆盖穿戴者与外骨骼整体的正常不可见防御能量场，防护强于L2。 |
| L4 | 罗小雨在EP26对练与EP30闸门战中使用的同一套装备 | 具有能量护罩；具体机动与武装仍按现有机体资料。 |
| L5 | `WTF-03／雾蛟`级别 | 2470年称为紧凑型机甲；具有能量护罩。 |
| L6 | 暗域场／暗域能量深度介入的最高现行等级 | 源组织与白塔采取不同防御路线；当前没有L7。 |

## L4与L5能量护罩

- L4和L5的护罩均为能量护罩，不是实体护罩或自动闭合的装甲外壳。
- L4和L5能量护罩正常情况下完全不可见，不显示透明罩体、发光球壳、光墙、波纹、收紧、展开、破裂或回缩效果；“不可见护罩”不等于没有能量护罩。
- L4和L5能量护罩同时保护机体与位于机体内部的穿戴者／驾驶者。
- 能量护罩可以阻挡物理攻击和能量攻击。
- 护罩不取消动量守恒。攻击被挡住后，冲击量仍会向机体传递或被重新分配，因此机体仍可后退、失衡、翻倒或被掀飞。
- “挡住攻击”不等于“机体绝对不动”，也不等于结构永不受压或受损；持续、集中或足够巨大的传入载荷仍可使护罩内侧机体凹陷、弯曲或损坏。机体损坏足够严重时，内部人员会因冲击、挤压或结构失效受伤。

## 各级防护形态边界

- L2是贴身人员基础能量场，只保护人体，不向外覆盖独立机体。
- L3是覆盖穿戴者与超紧凑型外骨骼整体的防御能量场；它比L2更强，但仍遵循动量守恒，也不保证外骨骼绝对不损坏。
- L4、L5是覆盖整套机体及内部人员的不可见能量护罩。
- 源组织L6采用生物硬化与渐进式减速场；白塔未来L6采用外层不可见能量护罩与贴肤第二重不可见缓冲壳。不同等级的能量场不得写成同一种可见特效。
- 时间顺序固定为源组织L6先进入剧情，白塔L6后续才开始研发并出现；EP31不得写成白塔L6已经研发、制造或交付。

## 调用边界

- 具体装备以本等级页与各自型号页共同为准；等级页不替代型号的结构、武器、能源和驾驶方式。
- 某一等级存在能量护罩，不得反推所有较低等级、同阵营机器人或所有外骨骼都具备护罩。
- 未被正式归级、且型号页也未明确记录护罩的装备，仍不得自行补造护罩。
- L2的细节只调用[旧白紫色巡检护甲套装](旧白紫色巡检护甲套装.md)；不得因“L2”重写其既有视觉或模块。
