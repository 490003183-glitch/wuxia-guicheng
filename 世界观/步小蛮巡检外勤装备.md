# 步小蛮巡检外勤装备

> 公开版｜来源状态：已确认。包含剧情剧透；文内未来节点及待确认项不代表已经发生。

## 定位

步小蛮的 2470 巡检 / 外勤装备属于L2白塔城市巡检系统中层巡检员配置，偶尔外勤，不是军队重装甲。它提供防护但不增强力量、速度、跳跃、反应或耐力。

## 总体风格

- 白色主装。
- 低饱和粉紫 / 淡紫功能结构。
- 有限荧光黄警示色。
- 工业磨损。
- 模块化真实穿戴逻辑。

## 装备结构

| 部位 | 设定 |
|---|---|
| 上身 | WT-LI Armor Type-C 白色模块化轻巡检胸甲，开放分段结构，无前胸能量核心。背部中央可有 T 型外部接口，为保留扩展接口，平时为空。 |
| 腰部 | 淡粉紫多功能值勤腰带，快拆模块、小包、身份 / 数据 / 通信 / 应急巡检工具。 |
| 下身 | 深灰短裙基底 + 白 / 淡紫分段轻量裙甲，不是传统 JK Cosplay，而是白塔功能行动裙甲。 |
| 腿部 | 高机动腿部行动 / 保护系统，膝盖缓冲，前小腿护板保护、踢击、缓冲；后小腿绝对无护板，保留皮肤露出以保持灵活、减重和视觉露出。 |
| 鞋 | WT Mobility Shoes，无鞋带的高机动白塔行动鞋，非军靴。脚尖金属强化，可用于自卫、踢击、破轻障碍；辅助快速跑动、跳跃、防滑、踝部保护。 |

- **鞋部硬规则**：行动鞋没有鞋带。任何小说、剧本、Seedance提示词和资产描述均不得出现系鞋带、鞋带松脱或重新绑紧。

## 当前视觉露出

- 巡检服采用开放式分段胸甲，保留肩臂与腰腹露出，不使用全覆盖紧身内层包住身体。
- 深灰短裙基底与分段裙甲长度较短，大腿在裙甲与膝部护板之间保持大面积露出。
- 这种露出属于白塔巡检服的正式功能与视觉设计，不需要另加专用驾驶服制造身体张力。

## 与 WTF-03 雾蛟的兼容

- 白塔巡检服本身可以直接进入 [WTF-03 雾蛟](WTF-03雾蛟机甲.md) 驾驶位，驾驶员无需更衣。
- 巡检服背部结构允许雾蛟机械脊柱从后颈至腰骶完成全长神经接驳，并双向传递驾驶意图与全机传感信号。
- 驾驶状态下，巡检服的胸甲、腰腹和大腿前侧仍位于机体正面开放区域，不被额外舱体或承托材料覆盖。
- 雾蛟对驾驶员的固定集中在脊柱贴合与大腿束缚，不依赖腰腹包覆。

## 基础能量场

- 该巡检服属于白塔人员能量护甲，具有人员级基础能量场；开放式甲片之间及视觉上露出的身体部位由基础能量场提供保护。
- 步小蛮进入正式作战状态时，至少穿戴这一防护规格的护具。
- 基础能量场完整运行时，星落现有双头重鞭、长尾黏弹与单发破甲榴弹都不能将其破坏或击穿；命中冲量仍可能令步小蛮后退、失衡或摔倒。
- 该能量场只保护穿戴者本人，不能把L2人员场写成向外覆盖机体；雾蛟／Aurea另按L5自身能量护罩口径执行。
- 该能量场依赖能量与电路维持，在泯灭场内停用。
- 完整边界见[白塔战斗人员基础能量场护具与机器人防护边界](白塔战斗人员基础能量场护具与机器人防护边界.md)。

## 与L3超紧凑型外骨骼的关系

- L3不是这套L2护甲的同义词或普通扩展模块，而是更高一级的超紧凑型外骨骼系统。
- L3同时增强力量、速度、跳跃、反应与耐力，并自带强于L2的防御能量场。
- EP30无人机只送达能量手枪；L3尚未到达。现行EP31正式小说已兑现：步小蛮弃旧L2、向罗小雨通话后，由林逸带无人机送达L3；先交还手枪、完成穿戴并由无人机运走枪，再在双水槽再次遭遇星落、温雅。
- 历史规划口径保留：2026-09-04曾记“再次遭遇时送来，具体方式待规划”；现由已确认第三十一章的先送达后遭遇顺序取代。
- [步小蛮L3超紧凑外骨骼与配套武器系统](步小蛮L3超紧凑外骨骼与配套武器系统.md)记录当前L3穿戴、推进、机械高跟足和配套武器的能力与用途；本页其余L2结构及禁用写法不扩大为对独立L3型号的限制。
- 完整分级见[2470护甲与机体等级体系](2470护甲与机体等级体系.md)。

## 禁用写法

- 不要写军队重装甲。
- 不要写前胸能量核心。
- 不要写飞弹舱展开、装甲展开、机械变形。
- 不要把枪挂写成腿环或挂枪腿环。
- 复合弓不能写成传统猎弓、夸张能量武器、数字瞄镜、全息 UI 或爆炸魔法箭。
