- 凌砚在底层刺杀暴露后立即冻结岑牧的医疗、高管和核心联合授权资格；岑牧从内部高管间谍转为逃亡中的外部行动者。

## 异兽阿尔法系定位

异兽阿尔法系是源组织基因改造动物型异兽，不是恶毒恐怖异形。它们本性并非纯恶，而是被源组织武器化。

## 视觉方向

- 干净、有毛发。
- 犬 / 狼型为主，带优雅猫科 / 豹类动作影响。
- 真实摄影科幻电影概念质量。
- 不要黏液、脏污、怪诞或过度生物机械。

## 通用特征

- 总共六只眼：每侧一只较大主眼 + 两只较小副眼。
- 长而优雅的尾巴。
- 尾尖不是机械，而是生物隐藏蜂针式注射功能。
- 正常状态下针刺收回，尾端柔软、圆润、有毛。
- 尾端前约 15cm 有轻微有机储囊 / 膨起。
- 注射效果可致命或清除记忆，但描述要临床化、世界观化，不血腥。

## 变体

| 名称 | 定位 |
|---|---|
| 异兽阿尔法 | 敏捷突击型，高机动、短爆发，需要恢复，寿命较短。 |
| 异兽阿尔法母体 | 稍大、更稳定，内部繁殖 / 分裂能力，不露出囊体或膨胀腹部，短暂光学伪装，自卫较弱但仍有攻击性。 |
| 异兽阿尔法二式 | 源组织未来战术改造版，颈部黑色控制项圈，提高服从与战斗效率，身体仍然是有机毛发，不赛博机械化。 |
| 异兽阿尔法未成年体 | 较小，好奇 / 学习型，背毛蓝紫色。 |

## 乔昔保护的无颈环个体

- 乔昔秘密保护并藏养一只没有源组织控制颈环的阿尔法异兽，正式名字为“圈圈”；它平时躲在由乔昔持续照料、保持干燥整洁的废弃维修通道里，不养在乔昔家中。
- 该个体爱吃乔昔亲手做的饼，是乔昔的宠物。
- 圈圈有很长的尾巴，性格与依恋方式像狗；它会围绕、贴近乔昔并以长尾环绕她的腿。感知危险时会咬住乔昔裙摆，试图把她拖向更狭窄的安全位置。
- 圈圈长尾靠近蓬松尾端的连接处装有乔昔制造的专属攻击尾环。圈圈竖起尾巴后，尾环旋转展开，向除圈圈自身位置外的周围三百六十度发射毒针。
- 该个体不自动等同于雾团／团团；具体变体与乔昔最初相遇经过仍待确认。第二十八章已正式写入步小蛮发现圈圈，第二十九章已写入白塔现场按“只攻击带颈环目标”排除圈圈。
- 详见 [乔昔保护的无颈环阿尔法异兽](../角色/乔昔保护的无颈环阿尔法异兽.md)。

## 公开版兽群行动边界

源组织把阿尔法武器化，并通过控制颈环约束它们。星落保留近距离三只精控及短暂接管其中一只的天然御兽能力；接管时本体反应降低，命令受异兽伤势、恐惧和身体能力限制。兽群袭击与区域封锁由源组织部署，星落个人能力限于上述近距离范围。

## 控制区与人命保护约定（2026-10-01新增）

- 源组织拥有源组织控制区，白塔拥有白塔控制区；地区范围及公开政治地位未定，保留原有阴影活动与秘密渗透资料。
- 双方有永久固化约定：非极端情况不伤人命。2470年人类繁育法案与人命的重要性，是大量使用机器人作战的背景；约定对人类存续至关重要，违约会产生复杂后果。
- 机器人武器仍可能致命，不能把机器人攻击人类自动等同于守约；第十八章队长杀同伴及第二十一章岑牧刺杀已确认为违约；小蛮极端防卫与乔昔意外致死的分别处理已确认，其他事件及追责方式仍待定义。详见[双方控制区与人命保护约定](白塔与源组织控制区及人命保护约定.md)。
